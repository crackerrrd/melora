МЕЛОРА — обновлённый визуальный прототип сайта
================================================

ЧТО ИЗМЕНИЛОСЬ
- Визуальное направление приведено к чёрно-белой базе из гайдлайна: чёрный и белый — основные цвета, серебряный хром — графический эффект, тёмно-синий и голубой не используются как доминирующие цвета.
- Использованы два предусмотренных гайдлайном варианта монограммы: на белом и на чёрном фоне. Пропорции и цвета логотипа не изменяются; логотип не пересекается декоративной графикой и отделён охранным пространством.
- Использован визуальный мокап упаковки и украшений из приложения к гайдлайну как концептуальный hero-образ; он явно обозначен как мокап, а не фото реального ассортимента.
- В CSS назначены именно фирменные гарнитуры Vetrino Regular для заголовков и Evolventa для основного текста. Для прототипа шрифты загружаются по HTTPS с внешнего источника; если сайт должен работать автономно или без зависимости от стороннего сервиса, правообладатель/заказчик должен предоставить и разместить лицензированные webfont-файлы на собственном домене. Источники: https://www.fonts.uprock.ru/fonts/vetrino и https://www.fonts.uprock.ru/fonts/evolventa.
- Обновлены карточки, кнопки, каталог, корзина и мобильное отображение под чёрно-белую основу. Хромовый эффект передан только нейтральными серебряными оттенками; тёмно-синий и голубой не используются как доминирующие цвета.
- В форме есть демонстрационный выбор доставки СДЭК. Это интерфейс-заглушка: настоящий тарифный расчёт и создание отправления не подключены.


ПРОВЕРКА ПО ГАЙДЛАЙНУ
- [x] основа интерфейса — чёрный #000000 и белый #ffffff.
- [x] дополнительные цвета из руководства зафиксированы точно: тёмно-синий #1d2d38 и голубой #78b9e5; голубой появляется только в доступном с клавиатуры фокус-состоянии, а не как доминирующий цвет.
- [x] используются утверждённые версии монограммы: чёрно-хромированная на белом фоне и серебряно-хромированная на чёрном фоне.
- [x] логотипы не поворачиваются, не перекрашиваются, не обрезаются, на них не накладывается декоративная графика; пропорции сохранены.
- [x] задан охранный отступ вокруг логотипа, а соседний текст отделён от знака.
- [x] заголовки назначены на Vetrino Regular, основной текст — на Evolventa; указаны запасные шрифты на случай недоступности фирменной гарнитуры.
- [x] тексты интерфейса оформлены со строчной буквы, кроме официального написания названий и сокращений.
- [x] фотографии товаров показаны в нейтральной монохромной гамме; мокапы помечены как концептуальные, чтобы не выдавать их за фотографии фактического ассортимента.
- [x] нет автозапуска звука; анимация короткая и отключается системной настройкой reduced motion.

ЧТО ПОКА НЕ ГОТОВО ДЛЯ РЕАЛЬНЫХ ПРОДАЖ
- Названия, цены и визуализации 4 изделий в script.js демонстрационные — замените их утверждённым каталогом (до 20 изделий).
- Корзина и форма работают только в браузере. Заявка не отправляется, заказ не сохраняется, онлайн-оплаты нет.
- Не подключены платёжный провайдер, касса, Telegram-уведомления, CRM, API СДЭК, домен и production-хостинг.
- До реального запуска в РФ нужно согласовать правовую модель продавца, кассовую схему, обязательные сведения для ювелирных изделий/ГИИС ДМДК, обработку персональных данных и документы для покупателей.

КАК ОТКРЫТЬ НА WINDOWS 10
1. Распакуйте архив в отдельную папку.
2. Откройте папку melora-site.
3. Дважды нажмите index.html — сайт откроется в браузере.
4. Проверьте навигацию, каталог, поиск, фильтры, сортировку, корзину и демонстрационную форму.

СТРУКТУРА ПРОЕКТА
- index.html — структура и тексты страниц.
- styles.css — адаптивный дизайн.
- script.js — демонстрационный каталог, поиск, фильтры, корзина и форма.
- assets/ — фирменные монохромные изображения и концептуальный мокап из вашего PDF.

ВАЖНО
Для публикации как статического прототипа подойдёт GitHub Pages или аналогичный хостинг. Для реального интернет-магазина с оплатой нужна платформа/серверная часть, которая хранит заказы и надёжно обрабатывает уведомления от платёжного провайдера. Одна лишь публикация HTML не обеспечивает приём денег и заказов.
